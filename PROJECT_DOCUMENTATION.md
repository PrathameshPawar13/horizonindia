# Images

Store all images inside:

```txt
public/images/
```

Examples:

```txt
public/images/hero.png
public/images/director.png
public/images/logo.png
```

Usage:

```tsx
<Image
  src="/images/hero.png"
  alt="Hero"
  fill
/>
```
